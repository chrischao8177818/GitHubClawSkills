# GitHubClawSkills

這個 repo 是 Codex Skill 的集合頁。

## 技能清單

| 技能名稱 | 路徑 |
|---|---|
| `cooking-video-summary` | [`cooking-video-summary/SKILL.md`](./cooking-video-summary/SKILL.md) |

## 安裝方式

把 `<owner>`、`<repo>`、`<skill-path>` 換成實際值即可。

```bash
install-skill-from-github.py --url https://github.com/<owner>/<repo>/tree/main/<skill-path>
```

```bash
install-skill-from-github.py --repo <owner>/<repo> --path <skill-path>
```

## 使用範例

```text
<skill-name> <來源網址或內容>
```

例如：

```text
cooking-video-summary https://www.youtube.com/watch?v=HWBpr2MH_bE
```
